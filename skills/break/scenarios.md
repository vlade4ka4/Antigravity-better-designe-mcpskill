# Stress Test Scenarios
- **Extremes of Text**: 1 character vs 500 characters of unbroken text (`WWWWWW...`).
- **Data Counts**: 0 items (empty state) vs 1,000 items (overflow/virtualization).
- **Narrow Containers**: 320px viewport container width.
- **RTL & Localization**: Pseudo-German (+35% text length) and Arabic RTL layout.
- **Async Failures**: Indefinite loading state vs server error state.
