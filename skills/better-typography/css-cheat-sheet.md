# Typography CSS & Tailwind Cheat Sheet
| Rule | CSS | Tailwind |
| :--- | :--- | :--- |
| Tabular Nums | `font-variant-numeric: tabular-nums` | `tabular-nums` |
| Balanced Wrap | `text-wrap: balance` | `text-balance` |
| Pretty Wrap | `text-wrap: pretty` | `text-pretty` |
| Measure 65ch | `max-width: 65ch` | `max-w-[65ch]` / `max-w-prose` |
