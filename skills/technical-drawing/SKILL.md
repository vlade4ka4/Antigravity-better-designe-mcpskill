# Technical Drawing

Produces parametric, CAD-grade 2D/3D technical illustrations with an interactive HTML viewer.

## Workflow
1. **Model Coordinate Space**: Build 3D parametric coordinate model (`./geometry.md`, `./geometry-library.md`).
2. **Project Views**: Generate orthographic, isometric, or exploded views (`./views-and-annotations.md`).
3. **Line Weights & Sheets**: Apply standardized line hierarchy (outlines 1.5px, internal edges 0.75px, centerlines 0.5px dashed) on standard sheet bounds (`./sheet-and-svg.md`).
4. **Visual Inspection**: Verify linework at 1x and 4x zoom (`./verification.md`).
5. **HTML Viewer**: Assemble standalone viewer page with color toggles and SVG/PNG/PDF download buttons (`./preview-page.md`, `./viewer-assets.md`).
